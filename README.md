# unipol-claude-ws-finsup

Prototipo e2e sviluppato durante l'Hagenthon (Accenture Application Engineering) — **Tema 02: Inclusione Finanziaria**.

Supporto all'educazione alla finanza personale di base per persone con bassa alfabetizzazione finanziaria. Niente consulenza finanziaria o raccomandazioni di investimento: l'obiettivo è far capire, non consigliare.
